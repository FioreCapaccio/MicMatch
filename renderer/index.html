MicMatch

Adatta il timbro di registrazioni fatte con microfoni diversi a una traccia di riferimento

1. Riferimento

Il "suono" a cui vogliamo che le altre tracce assomiglino: una traccia audio registrata, oppure la risposta in frequenza tipica di un modello di microfono.

Nessun file selezionato

2. Tracce da adattare

I file registrati con microfoni/ambienti diversi da correggere. Trascina qui uno o più file oppure scegli dal disco.

    3. Impostazioni

    Trascina un knob verso l'alto/basso per regolarlo (Shift = regolazione fine), rotellina del mouse per piccoli step, doppio click per il valore di default.

    Loudness: click singolo o trascinamento = scorre gli standard, rotellina del mouse = avanti/indietro, doppio click = torna a "Traccia di riferimento" (non disponibile in modalità "Microfono di riferimento").

    (sottocartella "matched" accanto ai file originali)
